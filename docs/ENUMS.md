# Traits

Ce package met à disposition plusieurs enums à des fins totalement différentes mais nécessaires dans chacun de nos projets.

## ActivityLogsEventEnum

[`ActivityLogsEventEnum.php`](./../src/Enums/ActivityLogsEventEnum.php): défini les évènements supportés par le package depuis un modèle.

| Méthode      | Description                     |
|--------------|---------------------------------|
| `created`    | Évènement de modèle création    |
| `updated`    | Évènement de modèle mise à jour |
| `duplicated` | Évènement de modèle duplication |
| `deleted`    | Évènement de modèle suppression |
